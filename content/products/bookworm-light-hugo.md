Bookworm Light is a clean, modern free Hugo blog theme with multi-author support and built-in search, ideal for any blogging niche.

### Key Features

- Google PageSpeed Score 96/100 (Desktop)
- Multi-author support
- Built-in search with Fuse.js and Mark.js
- Google Analytics support
- Contact form support via Formspree
- GDPR consent enabled
- Mailchimp integration
- Instagram feed integration
- Multiple language support
- Open Graph and Twitter Card meta tags
- CSS and JS bundling with Hugo Pipe
- Free updates and Premium Support
- Detail Documentation.
