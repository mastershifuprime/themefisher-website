NorthendLab Light is a minimal, responsive free Hugo blog theme for tech and gaming blogs with built-in search and multilingual support.

### Key Features

- Google PageSpeed Score 99/100 (Desktop)
- Google Analytics support
- CSS and JS bundle with Hugo Pipe
- Search functionality via Fuse.js and Mark.js
- GDPR consent enabled
- Multiple language support
- Multiple author support
- Mailchimp integration
- Customizable menu alignment and sidebar options
- Open Graph and Twitter Card meta tags
- Free updates and Premium Support
- Detail Documentation.
