Docbox is a clean and professional Hugo documentation theme perfect for software projects, APIs, libraries, and technical documentation sites. It provides an intuitive navigation structure, full-text search, and a readable layout that makes complex documentation easy to navigate.

### Key Features

- Full-Text Search
- Auto-generated Table of Contents
- Google PageSpeed Score 95+
- Netlify-Ready
- SEO-Ready
- Syntax Highlighting
- Multiple Language (i18n) Support
- Light/Dark Mode
- Images, CSS, and JS optimized with Hugo Pipe
- Free Update and Lifetime Premium Support
- Detail Documentation
