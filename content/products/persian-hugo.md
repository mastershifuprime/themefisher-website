Persian is a lightweight free Hugo blog theme featuring fast search, responsive design, and clean layouts optimized for bloggers and content creators.

### Key Features

- Google PageSpeed Score 98/100 (Desktop)
- Fast search functionality via Fuse.js
- 100% responsive design
- Contact form support via Formspree
- Netlify and Forestry integration
- Syntax highlighting
- Open Graph and Twitter Card meta tags
- Custom logo support
- Image, CSS, and JS optimization via Hugo Pipe
- Free updates and Premium Support
- Detail Documentation.
